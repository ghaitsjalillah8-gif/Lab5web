# Praktikum 5: JavaScript Dasar dan Manipulasi HTML

## Tujuan
Memahami JavaScript dasar, output, variabel, operator, function, percabangan, manipulasi DOM, form, dan validasi input.

## Isi Folder
- `index.html`: struktur halaman dan komponen latihan.
- `script.js`: logika JavaScript untuk latihan dan mini project.

## Cara Menjalankan
1. Ekstrak folder/ZIP.
2. Buka folder `lab5_javascript` di Visual Studio Code.
3. Buka `index.html` di browser (klik dua kali file atau gunakan ekstensi Live Server).
4. Tekan tombol pada setiap bagian latihan.
5. Untuk melihat Console, tekan `F12` lalu pilih tab Console.

## Latihan
1. Menampilkan output Hello World.
2. Alert dan prompt untuk nama pengguna.
3. Operasi aritmetika.
4. Seleksi kondisi if-else untuk nilai mahasiswa.
5. Seleksi switch untuk angka 1-5.
6. Pemeriksaan bilangan genap atau ganjil.
7. Mengubah warna latar halaman.
8. Menghitung total menu makanan dari checkbox.
9. Mini project kalkulator nilai mahasiswa.
